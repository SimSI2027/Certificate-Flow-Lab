Learning film: From CSR to Trust

How a website certificate request moves from a browser error to a trusted HTTPS connection, in 18 shots. The film is rendered live in your browser from the project's real synthetic fixtures; every frame is a pure function of time. It has no sound: every point is in the on-screen captions.

    About this film

    Keyboard: Space plays or pauses, the left and right arrow keys move between shots. With reduced motion, playback shows each caption's settled frame instead of continuous movement.

    The MP4 version (1920×1080, 60 fps, silent) is generated locally with npm run video:learning and is not stored in the repository.

    Synthetic simulation: SIMSI2027 names, addresses and events are invented. Nothing here connects to a real PKI, and no private keys are distributed.
